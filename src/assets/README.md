# Logos sociales

SVG locales utilizados por `src/components/ui/SocialLogo.astro`. Se conservan las formas y los colores de las fuentes oficiales; no se aplican máscaras CSS ni degradados adicionales.

| Archivo | Fuente oficial | Recurso |
| --- | --- | --- |
| `github.svg` | [GitHub Brand Toolkit](https://brand.github.com/foundations/logo) | `GitHub_Logos.zip` → `GitHub Logos/SVG/GitHub_Invertocat_White.svg` |
| `linkedin.svg` | [LinkedIn Brand Downloads](https://brand.linkedin.com/downloads) | Símbolo SVG `inbug-blue-28` publicado en esa página, extraído como SVG independiente conservando sus trazados y color. |
| `whatsapp.svg` | [WhatsApp Brand Resource Center](https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/) | `WhatsApp-Brand-Resource-Center.zip` → `01_Glyph/01_Digital RGB/03_SVG/Digital_Glyph_Green_RGB_2026.svg` |

Los logos pertenecen a sus respectivas marcas. Se usan para identificar los enlaces a esos servicios.
