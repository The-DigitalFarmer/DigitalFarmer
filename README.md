# DigitalFarmer · Portafolio pixel art

Portafolio con inicio, habilidades, proyectos, experiencia y contacto. HTML, CSS y JavaScript sin frameworks ni compilación.

## Editar

- `index.html`: nombre, textos y estructura del inicio.
- `styles.css`: paleta, tipografías, composición y adaptación móvil.
- `script.js`: paisaje pixelado y navegación entre secciones.
- `assets/`: imagenes editables.
